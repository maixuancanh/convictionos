# Submission assets

Keep public media assets in this folder only after they have been reviewed for:

- No credentials, account IDs, private broker identifiers, or deployment secrets.
- No fabricated P&L, balances, fills, screenshots, or leaderboard positions.
- No claim that real-money execution or return promises are available.
- Visible paper-only labels wherever trading status appears.

Final submission media should include a SaaS product walkthrough, dashboard proof, and receipt/claim evidence without exposing private data.
