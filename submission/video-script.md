# Video script

ConvictionOS is a paper-only autonomous options trading agent built for Alpaca.

Most AI trading demos ask you to trust a black box. ConvictionOS does the opposite. The AI can reason about market evidence, but deterministic risk gates decide whether an order is allowed.

Here is the product flow. A user lands on a commercial, trust-first page and opens Mission Control. The dashboard shows release identity, paper-only status, broker readiness, scheduler health, and current limitations.

The agent observes point-in-time evidence, asks a provider-agnostic model for grounded analysis, routes the idea through catalyst, swing, or thematic options mandates, checks risk, then uses Alpaca paper infrastructure for execution and reconciliation.

When the evidence is weak, the agent abstains. When it acts, the system records a receipt that explains what it knew, why it acted, which gates passed, and how broker state reconciled.

ConvictionOS does not promise returns. It is built to prove something more important first: AI trading can be auditable, paper-safe, operationally durable, and commercially understandable.
